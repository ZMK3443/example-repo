# Calculator App

## Project Description

This project is a simple Python calculator application that allows a user to enter two numbers and choose a mathematical operation (`+`, `-`, `x`, or `/`). The program validates user input to ensure numbers are entered correctly and prevents the program from crashing if invalid input is provided.

Once a calculation is performed, the result is displayed to the user and the full equation is saved to a file called **equations.txt** for record keeping. The program also includes error handling to manage issues such as non-numeric input and division by zero.
